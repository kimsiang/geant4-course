Make the muon spin visible, then measure a field with it.让缪子自旋显形，再用它测量磁场。

A polarized μ⁺ stops in copper inside a 10 mT field. Its spin turns at 1.355 MHz, and the decay positron remembers which way it pointed. Two counters, one ratio and one fit turn that into the field value. That only works if the physics list knows the muon has a spin.

极化的 μ⁺ 停在 10 mT 磁场中的铜靶里。它的自旋以 1.355 MHz 转动，衰变正电子记住了自旋当时的指向。两个计数器、一个比值和一次拟合就能把它变成磁场的数值。前提是物理列表知道缪子有自旋。

Theorem 12.1 · Muon spin precession缪子自旋进动

A stopped μ⁺ in a transverse field B precesses at f = (γμ/2π)·B, with γμ/2π = 135.5388 MHz/T. At 10 mT: f = 1.3554 MHz, period 0.738 µs, about three turns per lifetime (τμ = 2.1970 µs). Direction: dS/dt = γμ S × B with γμ > 0, so a spin starting along −z in B ∥ +x turns towards −y first.

横向磁场 B 中静止的 μ⁺ 以 f = (γμ/2π)·B 进动，γμ/2π = 135.5388 MHz/T。10 mT 时 f = 1.3554 MHz，周期 0.738 µs，每个寿命（τμ = 2.1970 µs）内约转三圈。方向：dS/dt = γμ S × B，γμ > 0，所以在 B ∥ +x 中初始沿 −z 的自旋先转向 −y。

Definition 12.1 · Decay asymmetry衰变不对称度

The positron from μ⁺ → e⁺ ν ν̄ is emitted preferentially along the muon spin: dN/dΩ ∝ 1 + a cos θ. Averaged over the whole positron energy spectrum a = 1/3; it rises to 1 for the most energetic positrons. With two opposite counters, N_U,D(t) ∝ e^(−t/τ)(1 ∓ A0 sin ωt) and A(t) = (N_D − N_U)/(N_D + N_U) = A0 sin(ωt + φ): the lifetime envelope cancels and the precession remains.

μ⁺ → e⁺ ν ν̄ 的正电子倾向于沿缪子自旋方向发射：dN/dΩ ∝ 1 + a cos θ。对整个正电子能谱平均，a = 1/3；能量最高的正电子 a 升至 1。用两个相对的计数器，N_U,D(t) ∝ e^(−t/τ)(1 ∓ A0 sin ωt)，A(t) = (N_D − N_U)/(N_D + N_U) = A0 sin(ωt + φ)：寿命包络相消，进动留了下来。

12.3 · Optical photons are a fidelity switch12.3 · 光学光子是一个保真度开关

/musr/command G4OpticalPhotons true    # off by default: photon counts explode

Optical transport means something only when the materials carry optical properties. It adds branches such as nOptPhot and odet_nPhot. Ask which observable needs information a parameterised response cannot keep: photon arrival times, surfaces, photocathode response. The muSR asymmetry needs only which counter fired and when, so it stays off this week (Week 5's parameterisation versus optical transport, again).

只有材料带有光学属性时，光学输运才有意义。它会增加 nOptPhot、odet_nPhot 等分支。要问：哪个可观测量需要参数化响应保留不了的信息？光子到达时间、表面、光阴极响应。μSR 不对称度只需要哪个计数器何时响应，所以本周不打开它（又一次是第 5 周的参数化与光学输运之争）。

TOY MODEL · approximations近似

        
Every muon stops at the target centre at t = 0 (in Geant4 it takes a few ns). Positron direction from 1 + a·S·n with a = 1/3, the energy-averaged Michel value, with no energy threshold and no copper or plastic in the way. Counters are cones of half-angle α around ±y; 44° matches the 80 mm wide slabs 42 mm from the target. The toy therefore expects A0 = a·P·(1 + cos α)/2 = 0.29. Our Geant4 run gives A0 = 0.241 ± 0.009, because positrons scatter and lose energy in the copper and the counters are square slabs, not cones. Field spread is Gaussian per muon. The frequency, its error and the fitted B behave as in the real analysis.

        
每个缪子都在 t = 0 时停在靶中心（在 Geant4 中需要几 ns）。正电子方向按 1 + a·S·n 抽样，a = 1/3 为能谱平均的 Michel 值，没有能量阈，也没有铜或塑料挡路。计数器被近似为绕 ±y 轴、半张角为 α 的圆锥；44° 对应距靶 42 mm、宽 80 mm 的板。所以玩具模型预期 A0 = a·P·(1 + cos α)/2 = 0.29。我们的 Geant4 运行给出 A0 = 0.241 ± 0.009，因为正电子在铜中散射并损失能量，而且计数器是方形板而不是圆锥。磁场弥散按每个缪子的高斯分布处理。频率、其误差以及拟合出的 B 与真实分析的行为相同。

    // Week 10: transverse-field muSR in plain Geant4 11.4, using the geometry of the textbook's tf_musr.mac.
// Usage:  ./week10 tf.mac            spin-aware muon decay (the physics a muSR study needs)
//         ./week10 tf.mac nospin     stock decay only: what an application gets if nobody adds spin
#include "ActionInitialization.hh"
#include "DetectorConstruction.hh"

#include "FTFP_BERT.hh"
#include "G4RunManagerFactory.hh"
#include "G4SpinDecayPhysics.hh"
#include "G4UIExecutive.hh"
#include "G4UImanager.hh"
#include "G4VisExecutive.hh"

#include <cstring>

int main(int argc, char** argv)
{
  auto* runManager =
    G4RunManagerFactory::CreateRunManager(G4RunManagerType::Default);
  runManager->SetNumberOfThreads(2);

  runManager->SetUserInitialization(new DetectorConstruction());

  auto* physics = new FTFP_BERT();
  const bool withSpin = !(argc > 2 && std::strcmp(argv[2], "nospin") == 0);
  if (withSpin) {
    // THE line of this week. FTFP_BERT's G4DecayPhysics uses G4Decay + G4MuonDecayChannel,
    // which "neglects muon polarization": no precession at rest, isotropic positrons, no asymmetry.
    // G4SpinDecayPhysics swaps in G4DecayWithSpin and G4MuonDecayChannelWithSpin.
    // Register it AFTER G4DecayPhysics (FTFP_BERT already contains it): it replaces "Decay".
    physics->RegisterPhysics(new G4SpinDecayPhysics());
  }
  runManager->SetUserInitialization(physics);
  runManager->SetUserInitialization(new ActionInitialization());
  // No Initialize() here: the macro sets /tf/B first, then calls /run/initialize.

  auto* uiManager = G4UImanager::GetUIpointer();
  if (argc > 1) {
    uiManager->ApplyCommand("/control/execute " + G4String(argv[1]));
  } else {
    auto* ui = new G4UIExecutive(argc, argv);
    auto* visManager = new G4VisExecutive();
    visManager->Initialize();
    uiManager->ApplyCommand("/control/execute vis.mac");
    ui->SessionStart();
    delete visManager;
    delete ui;
  }

  delete runManager;
  return 0;
}

G4VPhysicalVolume* DetectorConstruction::Construct()
{
  auto* nist = G4NistManager::Instance();
  auto* air = nist->FindOrBuildMaterial("G4_AIR");
  auto* cu = nist->FindOrBuildMaterial("G4_Cu");
  auto* scint = nist->FindOrBuildMaterial("G4_PLASTIC_SC_VINYLTOLUENE");

  // construct box World 400 400 400 ... (half-lengths, mm)
  auto* logicWorld = new G4LogicalVolume(new G4Box("World", 400 * mm, 400 * mm, 400 * mm), air, "World");
  auto* physWorld = new G4PVPlacement(nullptr, {}, logicWorld, "World", nullptr, false, -1, true);

  // construct box Target 15 15 3 G4_Cu 0 0 0 ... dead 5   -> 30 x 30 x 6 mm copper
  auto* logicTarget = new G4LogicalVolume(new G4Box("Target", 15 * mm, 15 * mm, 3 * mm), cu, "Target");
  new G4PVPlacement(nullptr, {}, logicTarget, "Target", logicWorld, false, 5, true);

  // construct box CounterU/CounterD 40 3 40 ... at y = +45 / -45 mm, IDs 11 / 1
  fLogicCounter = new G4LogicalVolume(new G4Box("Counter", 40 * mm, 3 * mm, 40 * mm), scint, "Counter");
  new G4PVPlacement(nullptr, {0, +45 * mm, 0}, fLogicCounter, "CounterU", logicWorld, false, 11, true);
  new G4PVPlacement(nullptr, {0, -45 * mm, 0}, fLogicCounter, "CounterD", logicWorld, false, 1, true);

  return physWorld;
}

void DetectorConstruction::ConstructSDandField()
{
  auto* sd = new CounterSD("TF/CounterSD");
  G4SDManager::GetSDMpointer()->AddNewDetector(sd);
  SetSensitiveDetector(fLogicCounter, sd);

  // globalfield TF 400 400 400 uniform 0 0 0 log_World 0.01 0 0  ->  Bx = 10 mT everywhere
  auto* field = new G4UniformMagField(G4ThreeVector(fB, 0., 0.));
  // Spin-aware equation of motion: 12 variables (x, p, t, ..., spin). Precession IN FLIGHT.
  // (Precession AT REST is done by G4DecayWithSpin, which reads this same field.)
  auto* equation = new G4Mag_SpinEqRhs(field);
  auto* stepper = new G4ClassicalRK4(equation, 12);
  auto* fieldManager = G4TransportationManager::GetTransportationManager()->GetFieldManager();
  fieldManager->SetDetectorField(field);
  fieldManager->SetChordFinder(new G4ChordFinder(field, 0.01 * mm, stepper));

  G4cout << "Field at (0,0,0): Bx = " << fB / tesla * 1000. << " mT  (printFieldValueAtPoint analogue)" << G4endl;
}

G4bool CounterSD::ProcessHits(G4Step* step, G4TouchableHistory*)
{
  const G4double edep = step->GetTotalEnergyDeposit();
  if (edep <= 0.) return false;
  const auto* pre = step->GetPreStepPoint();
  const G4int id = pre->GetTouchable()->GetCopyNumber();   // 11 = up, 1 = down
  const G4double t = pre->GetGlobalTime();
  fEdep[id] += edep;
  auto it = fTime.find(id);
  if (it == fTime.end() || t < it->second) fTime[id] = t;
  return true;
}

void SteppingAction::UserSteppingAction(const G4Step* step)
{
  const auto* track = step->GetTrack();
  if (track->GetParentID() != 0) return;                  // primary muon only
  const auto* proc = step->GetPostStepPoint()->GetProcessDefinedStep();
  if (!proc) return;
  const G4String& name = proc->GetProcessName();          // "DecayWithSpin" or plain "Decay"
  if (name != "DecayWithSpin" && name != "Decay") return;
  const G4int id = step->GetPreStepPoint()->GetTouchable()->GetCopyNumber();
  fEvent->SetDecay(step->GetPostStepPoint()->GetGlobalTime(), id,
                   step->GetPostStepPoint()->GetPolarization());
}

  fRun->detEdep.clear();
  fRun->detTimeStart.clear();

    fRun->detID.push_back(id);
    fRun->detEdep.push_back(e / MeV);
    fRun->detTimeStart.push_back(sd->Time().at(id) / microsecond);

  analysis->FillNtupleDColumn(0, fDecayTime > 0. ? fDecayTime / microsecond : -1000.);
  analysis->FillNtupleIColumn(1, fDecayDetID);
  analysis->FillNtupleDColumn(2, fSpin.y());
  analysis->FillNtupleDColumn(3, fSpin.z());
  analysis->FillNtupleIColumn(4, static_cast<G4int>(fRun->detID.size()));
  analysis->AddNtupleRow();   // vector columns are read at this moment
}

    asymmetry.pyANALYSIS
    """asymmetry.py -- recover the field from the precession of the muon spin (textbook 12.5, annotated).

Reads a t1 tree with musrSim branch names: the course app writes data/tf_10mT.root;
musrSim writes data/musrSim_0_tf.root for tf_musr.mac (run number 0, output name "tf").
Usage: python3 asymmetry.py [file.root] [--measured]
  --measured  use the counter's det_time_start instead of the truth muDecayTime
"""
import sys

import awkward as ak
import numpy as np
import uproot
from scipy.optimize import curve_fit

GAMMA_MU = 135.5388          # MHz/T, gamma_mu / 2pi (PDG / CODATA)

args = [a for a in sys.argv[1:] if not a.startswith("--")]
fname = args[0] if args else "data/musrSim_0_tf.root"
measured = "--measured" in sys.argv

D = uproot.open(fname)["t1"].arrays(
    ["det_ID", "det_time_start", "muDecayTime", "muDecayDetID"], library="ak")
sel = (D.muDecayDetID == 5) & (D.muDecayTime > 0)       # stopped AND decayed in the target; no sentinels
D = D[sel]
print(f"muons decayed in target: {len(D)}")

hitU = np.asarray(ak.any(D.det_ID == 11, axis=1))       # positron reached the UP counter (y = +45 mm)
hitD = np.asarray(ak.any(D.det_ID == 1, axis=1))        # ... the DOWN counter (y = -45 mm)
if measured:
    # what the electronics would see: the first time each counter fired
    tU = np.asarray(ak.fill_none(ak.firsts(D.det_time_start[D.det_ID == 11]), -1.0))[hitU]
    tD = np.asarray(ak.fill_none(ak.firsts(D.det_time_start[D.det_ID == 1]), -1.0))[hitD]
else:
    t = np.asarray(D.muDecayTime)                       # Monte Carlo truth (textbook choice)
    tU, tD = t[hitU], t[hitD]
print(f"positrons in U (ID 11): {len(tU)}   in D (ID 1): {len(tD)}")

bins = np.linspace(0, 10, 201)                          # 200 bins of 50 ns; T = 0.74 us at 10 mT
NU, _ = np.histogram(tU, bins=bins)
ND, _ = np.histogram(tD, bins=bins)
centre = 0.5 * (bins[:-1] + bins[1:])
tot = NU + ND
ok = tot > 20
A = (ND[ok] - NU[ok]) / tot[ok]                         # D first: mu+ spin turns from -z towards -y
Aerr = np.sqrt((1.0 - A**2) / tot[ok])                  # binomial split of tot counts
tg = centre[ok]


def osc(t, A0, f, phi, lam):
    return A0 * np.exp(-lam * t) * np.sin(2 * np.pi * f * t + phi)


popt, pcov = curve_fit(osc, tg, A, p0=[0.25, 1.35, 0.0, 0.05], sigma=Aerr, absolute_sigma=True)
perr = np.sqrt(np.diag(pcov))
chi2 = np.sum(((A - osc(tg, *popt)) / Aerr) ** 2)
ndf = len(A) - 4
f, df = popt[1], perr[1]
print(f"A0  = {popt[0]:.4f} +/- {perr[0]:.4f}")
print(f"f   = {f:.4f} +/- {df:.4f} MHz")
print(f"phi = {popt[2]:+.3f} +/- {perr[2]:.3f} rad    lambda = {popt[3]:.4f} +/- {perr[3]:.4f} /us")
print(f"chi2/ndf = {chi2:.1f}/{ndf}")
if abs(popt[0]) < 3 * perr[0]:
    # A fit always returns numbers. With no oscillation, f just stays near its starting value.
    print("WARNING: A0 is consistent with zero: there is no oscillation, so f and B are meaningless")
print(f"B   = {f / GAMMA_MU * 1000:.3f} +/- {df / GAMMA_MU * 1000:.3f} mT")

    field_scan.pyANALYSIS
    """field_scan.py -- Mission 12: fitted precession frequency versus configured field.
Usage: python3 field_scan.py data/tf_5mT.root data/tf_10mT.root data/tf_20mT.root data/tf_30mT.root
The configured field is read from the file name (tf_<B>mT.root).
"""
import re
import subprocess
import sys

import numpy as np

GAMMA_MU = 135.5388   # MHz/T

B, F, dF = [], [], []
for fn in sys.argv[1:]:
    out = subprocess.run([sys.executable, "asymmetry.py", fn], capture_output=True, text=True, check=True).stdout
    f, df = map(float, re.search(r"f   = ([\d.]+) \+/- ([\d.]+)", out).groups())
    b = float(re.search(r"tf_(\d+)mT", fn).group(1)) / 1000.0
    B.append(b); F.append(f); dF.append(df)
    print(f"B = {b*1000:5.1f} mT   f = {f:.4f} +/- {df:.4f} MHz   expected {GAMMA_MU*b:.4f}   pull {(f-GAMMA_MU*b)/df:+.2f}")

B, F, dF = map(np.asarray, (B, F, dF))
w = 1 / dF**2
# weighted straight line through the origin: f = k B
k = np.sum(w * B * F) / np.sum(w * B * B)
dk = 1 / np.sqrt(np.sum(w * B * B))
chi2 = np.sum(w * (F - k * B) ** 2)
print(f"slope k = {k:.3f} +/- {dk:.3f} MHz/T   (gamma_mu/2pi = {GAMMA_MU})   chi2/ndf = {chi2:.2f}/{len(B)-1}")
