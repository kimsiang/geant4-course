Background · Kinetic energy, momentum, mass动能、动量、质量

Geant4's particle gun sets kinetic energy, the energy of motion. Momentum p and kinetic energy T are linked by p = √(T² + 2Tm) in units where c = 1; the muon mass is m = 105.7 MeV. For a 1 GeV muon, p = 1.10 GeV/c. Above a few GeV, p and T are nearly equal, so muography papers often quote either.

Geant4 的粒子枪设定的是动能，即运动的能量。在 c = 1 的单位制中，动量 p 与动能 T 的关系是 p = √(T² + 2Tm)；缪子质量 m = 105.7 MeV。1 GeV 的缪子 p = 1.10 GeV/c。几个 GeV 以上时，p 和 T 几乎相等，所以缪子成像文献两种说法都有。

Background · Decay and time dilation衰变与时间膨胀

A muon at rest lives 2.197 µs on average and then decays into an electron and two neutrinos. A moving muon's clock runs slow by the factor γ = E/m. A 1 GeV muon (γ ≈ 10.5) travels about 7 km on average before decaying, so in any detector-sized world you will almost never see it decay in flight. Stopped muons, as in Week 10, do decay in front of you.

静止的缪子平均寿命 2.197 µs，之后衰变为一个电子和两个中微子。运动缪子的时钟按因子 γ = E/m 变慢。1 GeV 的缪子（γ ≈ 10.5）平均要飞约 7 km 才衰变，所以在探测器尺度的模拟世界里几乎看不到它在飞行中衰变。停下来的缪子（如第 10 周）才会在你面前衰变。

Background · Run, event, track, step in plain words用大白话说运行、事例、径迹、步

A run is one experiment with fixed settings, like one load case. An event is one muon arriving, plus everything it causes. A track is the path of one particle, including the electrons it knocks out. A step is one short segment of a track, ending at a material boundary or where something happens. Geant4 computes physics step by step, much as a time-stepping solver advances a structure.

一次运行是设置固定的一次实验，类似一个工况。一个事例是一个缪子到来及其引起的一切。一条径迹是一个粒子的路径，包括被它打出来的电子。一步是径迹中的一小段，在材料边界或发生某种过程时结束。Geant4 一步一步地计算物理，就像时间步进求解器一步步推进结构响应。

For muography projects用于缪子成像工程

A muography data set is millions of events, each one cosmic muon. Changing particle, energy, position and direction is exactly how you will later aim a simulated sky at a model of a hillside.

What Geant4 is doingGeant4 在做什么

For a primary muon, Geant4 creates a track, works out how far it can travel before the next boundary or physics interaction, moves it by one step, updates its state, and repeats until the track ends. The world is empty this week, so the physics is deliberately minimal: you learn the transport loop before adding matter.

对一个初级缪子，Geant4 先创建一条径迹，算出在下一个边界或物理相互作用之前它能走多远，把它推进一步，更新状态，如此循环直到径迹结束。本周的世界是空的，物理被刻意减到最少：先学输运循环，再加入物质。

Definition 2.1 · The Geant4 event modelGeant4 事件模型

A Run consists of one or more Events, all sharing the same detector construction and physics settings. Each Event contains one or more Tracks, each the complete history of a single particle from creation to termination. Each Track is divided into a sequence of Steps, each ending at a geometric boundary crossing or at the occurrence of a physics process.

一次运行（Run）包含一个或多个事件（Event），它们共享同一套探测器构建和物理设置；每个事件包含一条或多条径迹（Track），每条径迹是单个粒子从产生到消失的完整历史；每条径迹又被离散为一串步（Step），每一步结束于穿越几何边界或某个物理过程的发生。

Run → Event 0, Event 1, … → Track 1, Track 2, … → Step 1, Step 2, …

Example 2.1 · A minimal primary generator最小的初级粒子产生器

Configure the primary generator to fire a 1 GeV negative muon (μ⁻) along +z, starting inside the world and aimed toward its centre. In the official Geant4 examples this lives in a class called PrimaryGeneratorAction, derived from G4VUserPrimaryGeneratorAction. This course keeps that name throughout.

配置初级粒子产生器，沿 +z 方向发射一个 1 GeV 的负缪子（μ⁻），起点在世界内部、指向中心。在官方 Geant4 示例中，这段配置位于派生自 G4VUserPrimaryGeneratorAction 的 PrimaryGeneratorAction 类中，本课程沿用这个类名。

Code microscope · PrimaryGeneratorAction.ccGEANT4
fParticleGun->SetParticleDefinition(particle);                          // 1. species   ("mu-")
fParticleGun->SetParticleMomentumDirection(G4ThreeVector(0., 0., 1.));  // 2. direction (+z)
fParticleGun->SetParticleEnergy(1. * GeV);                              // 3. KINETIC energy
fParticleGun->SetParticlePosition(G4ThreeVector(0., 0., -1. * m));      // 4. position

void PrimaryGeneratorAction::GeneratePrimaries(G4Event* event)
{
  fParticleGun->GeneratePrimaryVertex(event);   // once per Event
}

Two details matter when you compare this with the official examples. First, GeneratePrimaries is called once per event, not once per run. If you want every event to sample a different energy or position, change the gun inside this method, not in the constructor. Second, SetParticleEnergy sets the kinetic energy, the quantity that enters γ = 1 + T/mc².

与官方示例对照时有两个细节。第一，GeneratePrimaries 每个事件调用一次，而不是每次运行调用一次；想让每个事件的能量或位置不同，就在这个函数里修改粒子枪，而不是在构造函数里。第二，SetParticleEnergy 设置的是动能，也就是 γ = 1 + T/mc² 中的 T。

/particle/property/dump2.3 · why nothing decays2.3 · 为什么没有衰变

The muon does not decay because 6.9 km is longer than 2.5 m, not because the world is empty.缪子不衰变，是因为 6.9 km 远大于 2.5 m，而不是因为世界是空的。

With no matter in the world, the muon loses no energy and scatters off nothing. It flies in a straight line at constant velocity until it leaves the world. History历史

Geant4 was developed by an international collaboration led by CERN to replace GEANT3, a Fortran code that had become hard to maintain, with an object-oriented framework for the LHC experiments. The first release came in 1998. The foundational paper, Agostinelli et al., Nucl. Instrum. Methods A 506 (2003) 250, made it a standard across high-energy, nuclear, medical and space physics, and muography.

Geant4 由 CERN 牵头的国际合作组开发，用面向对象框架取代难以维护的 Fortran 程序 GEANT3，服务于 LHC 实验。首个正式版本发布于 1998 年。奠基论文 Agostinelli 等，Nucl. Instrum. Methods A 506 (2003) 250，使其成为高能物理、核物理、医学物理、空间科学以及缪子成像领域的事实标准。

    #include "ActionInitialization.hh"
#include "DetectorConstruction.hh"

#include "G4RunManagerFactory.hh"
#include "G4UIExecutive.hh"
#include "G4UImanager.hh"
#include "G4VisExecutive.hh"

int main(int argc, char** argv)
{
  // Week 2 runs single-threaded so /tracking/verbose output is not
  // interleaved between worker threads. The textbook's main.cc uses
  // G4RunManagerType::Default; we switch to it when we merge MT output.
  auto* runManager =
    G4RunManagerFactory::CreateRunManager(G4RunManagerType::Serial);

  runManager->SetUserInitialization(new DetectorConstruction());
  runManager->SetUserInitialization(new FTFP_BERT());
  runManager->SetUserInitialization(new ActionInitialization());
  runManager->Initialize();

  auto* uiManager = G4UImanager::GetUIpointer();
  if (argc > 1) {
    // batch mode: ./week02 run1.mac
    uiManager->ApplyCommand("/control/execute " + G4String(argv[1]));
  } else {
    // interactive mode: open the viewer
    auto* ui = new G4UIExecutive(argc, argv);
    auto* visManager = new G4VisExecutive();
    visManager->Initialize();
    uiManager->ApplyCommand("/control/execute vis.mac");
    ui->SessionStart();
    delete visManager;
    delete ui;
  }

  delete runManager;
  return 0;
}

                           nullptr, false, 0, true);
}

PrimaryGeneratorAction::PrimaryGeneratorAction()
{
  G4int n_particle = 1;
  fParticleGun = new G4ParticleGun(n_particle);
