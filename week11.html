Background · V&V, as in engineering工程中的 V&V

Engineers already know verification and validation from computational mechanics: first check that the code solves its equations correctly, then compare it with experiments. Geant4 work follows the same order. Debugging is verification; comparing with the PDG tables or a field measurement is validation.

工程师在计算力学中已经熟悉“检验与验证”：先确认代码正确地求解了方程，再与实验比较。Geant4 工作遵循同样的顺序。调试属于检验；与 PDG 表或野外测量比较属于验证。

Background · What "σ" means“σ”是什么意思

σ is a standard deviation, the typical size of random scatter. For a Gaussian error, 68% of repeated measurements fall within 1σ and 95% within 2σ. A difference of 0.7σ is ordinary noise; 3σ or more deserves an explanation. Always state which uncertainties went into σ.

σ 是标准差，即随机涨落的典型大小。对于高斯误差，重复测量有 68% 落在 1σ 以内，95% 落在 2σ 以内。0.7σ 的差别是普通涨落；3σ 以上就需要解释。一定要说明 σ 包含了哪些不确定度。

For muography projects用于缪子成像工程

Before trusting a density map, validate the simulation where the answer is known: the open-sky rate and its zenith-angle dependence at the site, and a calibration run through a known thickness such as a building or a tunnel section with surveyed overburden.

在相信一张密度图之前，先在答案已知的地方验证模拟：现场开阔天空的计数率及其随天顶角的变化，以及穿过已知厚度的标定测量，比如一栋建筑或覆盖层已测绘的一段隧道。

New to muons, units such as g/cm² or m.w.e., or muography? Start with the background primer.还不熟悉缪子、g/cm² 或米水当量这类单位，或缪子成像？先读入门背景。

Retrace the path you took to build the system, and find where it left your expectation.沿着搭建系统的路径倒走一遍，找出它在哪里偏离了你的预期。

Definition 11.1 · Debugging tree调试决策树

A causally ordered checklist that narrows a vague symptom to one code-level culprit: generated? → geometry? → entered the detector? → physics enabled? → sensitive detector attached? → hit generated? → data recorded? → analysis correct? Investigate in the same order every time. That fixed order is what makes debugging a skill you can transfer to the next project.

一份按因果排序的检查清单，把模糊的症状收窄到代码中的某一处：产生了吗？→ 几何对吗？→ 进入探测器了吗？→ 物理过程开了吗？→ 灵敏探测器挂上了吗？→ 产生击中了吗？→ 数据记录了吗？→ 分析对吗？每次都按同样的顺序排查。正是这个固定顺序，让调试成为能带到下一个项目的技能。

我们在最前面加了第 0 层：偏差到底有没有超过 2–3σ？落在合成不确定度之内的差别并不是 bug 的证据。检查它只需一行算术，在我们的故障实验里它能省掉六次排查中的一次。每一层都有一个低成本的检查：

AI-assisted debugging: delegate syntax, keep the physicsAI 辅助调试：语法可以交出去，物理留给自己

An assistant (Claude, Gemini, DeepSeek) is a fast way to navigate the Geant4 API if you give it evidence, not "my code is broken". Ask for hypotheses you can test, and keep the decisions about what a hit is, which units, thread safety and validation for yourself. "It compiles" is never the acceptance criterion: require a minimal diff, a smoke test, a numerical sanity check and a comparison with an independent expectation. Never paste credentials, unpublished collaboration data or proprietary code into an external service.

如果你给 AI 助手（Claude、Gemini、DeepSeek）的是证据而不是“我的代码坏了”，它是浏览 Geant4 API 的快捷方式。请它提出你能检验的假设；什么算击中、用什么单位、是否线程安全、怎样验证，这些决定留给自己。“能编译”永远不是验收标准：要求最小改动、冒烟测试、数值合理性检查，以及与独立预期的比较。绝不要把凭据、未发表的合作组数据或专有代码贴进外部服务。

discrepancy_sigma()11.2 · what counts as validated11.2 · 什么才算“验证”

A simulation producing a number is not the same as that number being trustworthy.模拟算出一个数，不等于这个数值得信任。

Definition 11.2 · Levels of validation验证的层级

1 executable: runs and produces a defined observable. 2 sanity checked: units, conservation, limiting cases, geometry, numerical stability. 3 physics benchmarked: compared with an analytic result or established reference over a defined domain. 4 detector benchmarked: detector response compared with independent measurements. 5 predictively validated: reproduces an observable not used to tune it. 6 domain qualified: remaining assumptions, uncertainties and failure modes documented. A result can pass one rung and fail the next. Use this ladder instead of "fully validated".

1 可执行：能运行并给出定义明确的可观测量。2 完整性检查：单位、守恒、极限情形、几何、数值稳定性。3 物理基准：在限定范围内与解析结果或公认参考比较。4 探测器基准：探测器响应与独立测量比较。5 预测性验证：重现未用于调参的可观测量。6 领域限定：剩余假设、不确定度和失效模式均有记录。一个结果可以通过某一阶而在下一阶失败。用这个阶梯代替“完全验证”。

The comparison itself is one line: |sim − ref| / √(σ_sim² + σ_ref,stat² + σ_ref,sys²). It never compares two numbers directly, only their difference in units of combined uncertainty. It also assumes that sim and ref are the same quantity, and that is where both of our Lab 11.2 "discrepancies" came from.

比较本身只有一行：|sim − ref| / √(σ_sim² + σ_ref,stat² + σ_ref,sys²)。它从不直接比较两个数，只比较它们的差相对于合成不确定度有多大。它还默认 sim 和 ref 是同一个量，而我们实验 11.2 中的两个“不一致”都出在这里。

      #!/bin/bash
# make_faults.sh -- Lab 11.1: turn a working week05 counter into a git repository with one
# deliberately broken simulation per branch (fault-1 ... fault-6). Each fault is one line or one
# setting, compiles, and runs. The edits are stored base64-encoded so that running the script does
# not tell you what they are. Self-paced? Run it, do NOT decode it, diagnose every branch first;
# the answers are in FAULTS_ANSWERS.md.
# Usage: bash make_faults.sh path/to/week05 faultlab
#        cd faultlab && git branch          # main, fault-1 ... fault-6
set -euo pipefail
SRC=$1; OUT=${2:-faultlab}
rm -rf "$OUT"; mkdir -p "$OUT"
# copy the sources, never a build directory: its CMakeCache.txt points at the old source tree
(cd "$SRC" && tar --exclude=./build --exclude='./*.log' --exclude='./*.root' -cf - .) | (cd "$OUT" && tar -xf -)
cd "$OUT"
printf 'build/\n*.log\n*.root\n' > .gitignore
git init -q -b main && git add -A && git commit -qm "working counter (week05)"

d () { echo "$1" | base64 -d; }
fault () {   # fault <n> <file, encoded> <sed expression, encoded>
  local f; f=$(d "$2")
  git checkout -q -b "fault-$1" main
  sed -i "$(d "$3")" "$f"
  git diff --quiet && { echo "fault-$1: pattern not found (is $SRC the course's week05?)"; exit 1; }
  git commit -qam "fault-$1"            # the message gives nothing away
  git checkout -q main
}

      validate_dedx.pyANALYSIS
      """validate_dedx.py -- Lab 11.2: compare Geant4's mean muon energy loss in plastic scintillator
with the PDG muon table, and say which rung of the validation ladder that comparison reaches.

Input: edep_<T>MeV*.root files from the week04 app (10 cm of G4_PLASTIC_SC_VINYLTOLUENE), whose
"PrimarydEdx" histogram holds, per event, the primary muon's kinetic-energy loss / path [MeV/cm].
Usage: python3 validate_dedx.py edep_0100MeV.root edep_1000MeV.root ...

Two rules this script enforces, both learned the hard way in our own runs:
  1. Compare like with like. The muon slows down inside 10 cm, so the reference is the PDG table
     INTEGRATED along the path, not the table value at the entrance energy.
  2. A histogram mean ignores entries outside its range. If anything overflowed, the mean is a
     truncated mean and is not comparable with the PDG mean: the script refuses to give a sigma.
"""
import re
import sys

import numpy as np
import uproot

RHO = 1.032    # g/cm3, PDG polyvinyltoluene (I = 64.7 eV)
L = 10.0       # cm of scintillator in the week04 app
# PDG 2024, muE_polyvinyltoluene.txt: kinetic energy [MeV], total dE/dx [MeV cm2/g]
T_TAB = np.array([50, 55, 60, 70, 80, 90, 100, 120, 140, 170, 200, 250, 300, 324.6, 350, 400, 450, 500,
                  550, 600, 700, 800, 900, 1000, 1200, 1400, 1700, 2000, 2500, 3000, 3500, 4000, 4500,
                  5000, 5500, 6000, 7000, 8000, 9000, 10000, 12000], dtype=float)
S_TAB = np.array([2.861, 2.744, 2.647, 2.498, 2.388, 2.303, 2.237, 2.143, 2.082, 2.025, 1.992, 1.966,
                  1.957, 1.957, 1.957, 1.962, 1.969, 1.978, 1.987, 1.997, 2.016, 2.034, 2.051, 2.067,
                  2.096, 2.121, 2.153, 2.181, 2.219, 2.249, 2.275, 2.297, 2.317, 2.334, 2.350, 2.364,
                  2.389, 2.410, 2.429, 2.445, 2.474])
REF_SYS = 0.01   # ASSUMPTION: 1% on the tabulated value (mean excitation energy I); not quoted by PDG


def pdg_dedx(T):
    """Total stopping power at kinetic energy T [MeV], in MeV/cm (log-log interpolation)."""
    return RHO * np.exp(np.interp(np.log(T), np.log(T_TAB), np.log(S_TAB)))


def pdg_path_average(T0, n=2000):
    """Mean energy loss per cm over L, integrating dT/dx = -dE/dx(T) through the slab."""
    T, dx = T0, L / n
    for _ in range(n):
        T -= pdg_dedx(T) * dx
    return (T0 - T) / L, T


def discrepancy_sigma(sim, sim_unc, ref, ref_stat, ref_sys=0.0):
    """Discrepancy in combined-sigma units. Evidence for a comparison, not a verdict."""
    return abs(sim - ref) / np.sqrt(sim_unc**2 + ref_stat**2 + ref_sys**2)


def chi2_sf(x, k):
    """P(chi2 >= x) for k degrees of freedom."""
    from scipy.stats import chi2
    return float(chi2.sf(x, k))


pulls_stat, pulls_ref = [], []
for fn in sys.argv[1:]:
    T = float(re.search(r"edep_(\d+)MeV", fn).group(1))
    h = uproot.open(fn)["PrimarydEdx"]
    vals = h.values(flow=True)
    outside = vals[0] + vals[-1]
    sw = h.member("fTsumw")
    mean = h.member("fTsumwx") / sw
    rms = np.sqrt(h.member("fTsumwx2") / sw - mean**2)
    err = rms / np.sqrt(sw)
    entry = pdg_dedx(T)
    ref, Tout = pdg_path_average(T)
    print(f"T = {T:6.0f} MeV  Geant4 {mean:.4f} +/- {err:.4f} MeV/cm | PDG at entry {entry:.4f}, "
          f"path-averaged {ref:.4f} (exits at {Tout:.1f} MeV)")
    if outside > 0:
        print(f"           REFUSED: {outside:.0f} of {h.member('fEntries'):.0f} entries outside the histogram range; "
              f"this mean is truncated. Widen the range (/analysis/h1/set) and rerun.")
        continue
    ns = discrepancy_sigma(mean, err, ref, 0.0, REF_SYS * ref)
    pull = (mean - ref) / err
    pulls_stat.append(pull)
    pulls_ref.append((mean - ref) / np.sqrt(err**2 + (REF_SYS * ref) ** 2))
    print(f"           ratio {mean / ref:.4f}   discrepancy {ns:.1f} sigma (stat + 1% reference)   "
          f"stat-only pull {pull:+.1f}")
if len(pulls_stat) >= 2:
    # Look at both. Statistics alone tests whether Geant4 and the table agree to the precision of
    # the run; the 1% is an ASSUMED reference error. If it makes chi2/ndf much smaller than 1, the
    # assumed error is larger than the scatter of the points and hides any common offset.
    n = len(pulls_stat)
    c2s, c2r = float(np.sum(np.square(pulls_stat))), float(np.sum(np.square(pulls_ref)))
    print(f"stat only: chi2 = {c2s:.1f}/{n} (p = {chi2_sf(c2s, n):.2f})   "
          f"with the assumed 1% reference: chi2 = {c2r:.2f}/{n} (p = {chi2_sf(c2r, n):.3f})")
print("Ladder: physics benchmarked against a calculated table over 10 cm of plastic. Not yet detector "
      "benchmarked: no measured spectrum, threshold or trigger has been compared.")
