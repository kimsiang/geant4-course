Twelve weeks, one virtual laboratory.十二周，一座虚拟实验室。

Each week is one run: a question, a short lesson, a toy model you can play with, a task you run in your own terminal, and a self-check. You start with a Python Monte Carlo and finish with a virtual experiment you can defend in front of a referee.

每一周就是一次运行：一个问题、一段简短讲解、一个可以动手玩的玩具模型、一个在你自己终端里完成的任务，以及一组自测题。从一个 Python 蒙特卡罗开始，到一个能在审稿人面前答辩的虚拟实验结束。
