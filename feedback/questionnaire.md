# Geant4 2.0 · Student feedback questionnaire (v1)

Reusable with real cohorts. Scales: **L5** = 1 strongly disagree … 5 strongly agree; **D5** = 1 far too easy … 3 right … 5 far too hard; **N10** = 0–10. Every "problem" answer must name the page and section (e.g. `week04 · 4.1 The Bethe formula`) and, where possible, quote the words.

## A. About you (A1–A10)
- A1 Field and level of study / job.
- A2 Prior experience: programming (C++, Python, Linux shell), each 0–4 (none · tutorial · coursework · project · professional).
- A3 Prior physics: particle/nuclear physics, statistics, Monte Carlo, each 0–4.
- A4 Prior Geant4 / ROOT / musrSim use (none / tried / used in a project).
- A5 Preferred language mode (EN · 中文 · EN+中) and English reading comfort (L5).
- A6 Main device(s), operating system, screen size, network location (mainland China or not).
- A7 Hours per week you can study.
- A8 Why you took the course; what you want to be able to do at the end.
- A9 Track chosen (physics / muography) and whether you read the primer first.
- A10 Any accessibility needs (vision, reading, motor, time zone).

## B. First contact and onboarding (B1–B10)
- B1 L5 The course home made clear what I will learn, how long it takes, and what I need beforehand.
- B2 L5 I knew where to start (primer vs Week 1) for my background.
- B3 L5 The time estimates looked realistic.
- B4 L5 The navigation (item list, Next, Mark as complete, progress) was obvious.
- B5 Describe your software setup attempt: what you installed, where it failed, how long it took (minutes).
- B6 L5 Install instructions were sufficient to get Geant4 11.4 + Python stack working.
- B7 L5 The prerequisites (C++, Linux, physics) were stated honestly.
- B8 Did anything load slowly or break (fonts, 3D displays, GIFs)? Where?
- B9 L5 The primer prepared me for Week 1–3.
- B10 Which primer section was most / least useful, and why?

## C. Per-week block (repeat for each week you studied; C1–C12 per week)
- C1 L5 The goals told me what I would be able to do.
- C2 L5 The lesson text was clear.
- C3 D5 Difficulty.
- C4 Actual time spent (minutes) vs the page estimate.
- C5 L5 The background section helped (non-physicists especially).
- C6 L5 The interactive toy helped me understand the idea; did it work on my device?
- C7 L5 The 3D event display / figures helped (if present).
- C8 Lab outcome: completed / completed with help / partially / not attempted / blocked — and the step where you got stuck.
- C9 L5 My output matched the expected output closely enough to know I was right.
- C10 L5 The common-errors box covered the error I actually hit.
- C11 The single most confusing sentence, equation or step (quote it).
- C12 One concrete fix for this week.

## D. Learning design across the course (D1–D8)
- D1 L5 Predict → simulate → compare made me think, not just copy.
- D2 L5 Weeks build on each other in a sensible order.
- D3 L5 The amount of reading per week is right.
- D4 L5 Definitions, theorems and worked examples are numbered and easy to refer to.
- D5 L5 The jump from Python (Week 1) to C++ Geant4 (Week 2) was manageable.
- D6 L5 The musrSim / μSR weeks (9–10) are worth it for my track.
- D7 L5 The capstone (Week 12) is clear: what to hand in and how it is judged.
- D8 Which week would you cut, split or add?

## E. Assessment and feedback (E1–E7)
- E1 L5 Quiz questions test understanding, not memory.
- E2 L5 Quiz explanations taught me something even when I was right.
- E3 L5 I could tell whether my lab result was correct without asking anyone.
- E4 L5 I would like automatic checks of my lab numbers.
- E5 L5 The completion / progress tracking motivates me.
- E6 Any quiz question you think is wrong, ambiguous or has two right answers (quote it).
- E7 What would make you trust that you have *learned* Geant4 (certificate, project, exam)?

## F. Language and bilingual quality (F1–F6)
- F1 L5 The Chinese text reads naturally (not machine-translated).
- F2 L5 The English text is plain and easy to read.
- F3 L5 Technical terms are consistent between languages and across weeks.
- F4 L5 EN+中 mode is useful.
- F5 Any mistranslation or term inconsistency (quote both versions).
- F6 Any text that appears only in one language.

## G. Interface, accessibility and devices (G1–G8)
- G1 L5 Pages are comfortable to read on my main device.
- G2 L5 Code blocks, tables and figures are usable on my screen size.
- G3 L5 Dark mode / light mode both look right.
- G4 L5 I could use the course with keyboard / zoom / screen reader (if relevant).
- G5 L5 3D displays and toys run smoothly; controls are understandable.
- G6 L5 Copy buttons, collapsible files and progress ticks work as expected.
- G7 Any visual bug (overlap, cut-off text, wrong colour) — page and section.
- G8 Anything you looked for and could not find (search, glossary, downloads, PDF, index of commands).

## H. Physics and technical correctness (H1–H5)
- H1 L5 I trust the physics numbers on the pages.
- H2 L5 Approximations in toys and figures are clearly labelled.
- H3 Any number, unit, sign or formula you think is wrong (quote + why).
- H4 Any code that would not compile or run as written (file, line, error).
- H5 L5 The Geant4 practices taught match current (11.4) best practice.

## I. Support and community (I1–I5)
- I1 L5 I knew where to ask for help.
- I2 How did you get unstuck (search, AI assistant, classmate, instructor, gave up)?
- I3 Which support would you use: forum, WeChat group, office hours, TA code review, recorded walkthroughs?
- I4 L5 I would like short videos for the labs.
- I5 L5 I felt part of a cohort.

## J. Value and outcome (J1–J8)
- J1 N10 How likely are you to recommend the course to a colleague? (NPS)
- J2 L5 The course was worth the time I spent.
- J3 What price would be fair (range, currency) for: self-paced only / with support / with certificate?
- J4 L5 I can now set up a Geant4 simulation for my own project.
- J5 L5 I can validate a simulation result and defend it.
- J6 Best part of the course.
- J7 Worst part of the course.
- J8 The one change that would most improve it.

## K. Open (K1–K3)
- K1 What surprised you?
- K2 What did you expect that was missing?
- K3 Anything else.
