Make it realistic: physics lists and the trade-offs behind them.让模拟更真实：物理列表及其背后的取舍。

One particle has many possible fates. A physics list decides which of them can happen at all, and a production cut decides which of them become tracks. Both are physics decisions. A wrong one does not crash. It finishes quietly with the wrong answer.

一个粒子有许多可能的命运。物理列表决定哪些命运可能发生，产生阈决定其中哪些会变成径迹。两者都是物理上的决定。选错了不会崩溃，而是安静地给出错误答案。

Reading阅读6 min6 分钟

/control/echo backgroundbackground · for non-physicists背景知识 · 写给非物理专业

A physics list is the material model of a particle simulation.物理列表就是粒子模拟中的“本构模型”。

Background · What a physics list is物理列表是什么

In finite-element work you choose a constitutive model, linear elastic or plastic, and the answer depends on it. A Geant4 physics list plays the same role: it decides which interactions exist, such as ionisation, scattering, photon processes, nuclear reactions and decay. A missing process gives no error message, only a wrong answer.

在有限元分析中，你要选本构模型（线弹性还是塑性），答案依赖于它。Geant4 的物理列表起同样的作用：它决定存在哪些相互作用，例如电离、散射、光子过程、核反应和衰变。缺少某个过程不会报错，只会给出错误的答案。

Background · Production cuts产生阈

Following every tiny electron knocked out by a muon would be very slow. A production cut tells Geant4 not to create secondaries that would travel less than a set distance (0.7 mm by default) and to deposit their energy locally instead. It is like choosing a mesh size: too coarse loses detail, too fine wastes time.

追踪缪子打出的每个微小电子会非常慢。产生阈告诉 Geant4：射程短于设定距离（默认 0.7 mm）的次级粒子不再单独产生，其能量就地沉积。这就像选网格尺寸：太粗丢细节，太细浪费时间。

For muography projects用于缪子成像工程

For muon transport through rock, standard electromagnetic physics with muon processes and decay carries most of the result; a reference list such as FTFP_BERT includes them. Hadronic physics matters for backgrounds (neutrons, showers) and for very deep sites. For scattering muography, compare multiple-scattering models, because the scattering angle is the signal.

对于缪子穿过岩石的输运，标准电磁物理加上缪子过程和衰变决定了大部分结果，FTFP_BERT 这样的参考列表包含了它们。强子物理对本底（中子、簇射）和很深的场地才重要。做散射式缪子成像时，要比较不同的多次散射模型，因为散射角本身就是信号。

New to muons, units such as g/cm² or m.w.e., or muography? Start with the background primer.还不熟悉缪子、g/cm² 或米水当量这类单位，或缪子成像？先读入门背景。

/process/list6.1 · many possible fates6.1 · 许多可能的命运

A process is included because an observable depends on it.纳入一个过程，是因为某个可观测量依赖它。

Ionisation is only one thing a muon does in matter. It also scatters off Coulomb fields, now and then radiates a photon, makes an e⁺e⁻ pair, and at high energy can interact with a nucleus. A realistic simulation manages the whole family at once. Physics lists package these models; the choice of models is part of the scientific specification of a simulation.

电离只是缪子在物质中做的事情之一。它还会在库仑场中散射，偶尔辐射光子、产生 e⁺e⁻ 对，在高能时还可能与原子核相互作用。真实的模拟要同时处理这一整族过程。物理列表把这些模型打包在一起；选择哪些模型，本身就是模拟科学规格的一部分。

Definition 6.1 · Physics list物理列表

A physics list (G4VModularPhysicsList) is a bundle of processes and models declaring, for one simulation, which particles undergo which interactions, described by which model. Geant4 ships validated reference lists such as FTFP_BERT and QGSP_BERT, each tuned for a regime or application; you can also assemble your own.

物理列表（G4VModularPhysicsList）是一组过程与模型的集合，为一次模拟声明哪些粒子经历哪些相互作用、由哪个模型描述。Geant4 提供经过验证的参考列表，如 FTFP_BERT 和 QGSP_BERT，各自针对不同能区或应用调校；你也可以自行组装。

physics list = electromagnetic + decay + hadronic + extra (γ/μ-nuclear)
separate controls: production cuts (which secondaries become tracks) · user limits (step, track length, time)

Example 6.1 · Lab 6: swap the physics list, see what changes实验 6：更换物理列表，看看什么改变了

Keep geometry and gun fixed (a 1 GeV muon through 10 cm of lead). Run FTFP_BERT, then a list stripped to electromagnetic and decay physics. Compare the species and count of secondaries. Without hadronic physics, any secondary that should come from a hadronic interaction simply disappears, with no error at all.

Production cuts: a range, not an energy产生阈：一个射程，而不是能量

Geant4 does not produce a δ-ray, a bremsstrahlung photon or a positron as a track if it would travel less than the range cut (0.7 mm in FTFP_BERT). The range is converted per material into an energy threshold: 1.01 MeV for e⁻ in lead, 282 keV in plastic, 990 eV in air. Energy below the threshold is deposited continuously along the step instead. Nothing is thrown away. Particles that are produced are tracked down to a low tracking limit (1 keV for e± by default in 11.4, set by G4EmParameters), where their remaining energy is deposited. The cut sets the spatial resolution with which secondaries are followed. It is not a tracking cut. It applies to ionisation (δ-rays), bremsstrahlung and e⁺e⁻ pair production by charged particles; photoelectric absorption, Compton scattering and γ conversion create their secondaries whatever the cut, unless you switch that on explicitly.

如果一个 δ 电子、轫致辐射光子或正电子的射程短于射程阈（FTFP_BERT 中为 0.7 mm），Geant4 就不会把它作为径迹产生。这个射程按材料换算成能量阈值：铅中 e⁻ 为 1.01 MeV，塑料中为 282 keV，空气中为 990 eV。阈值以下的能量改为沿步连续沉积。没有任何能量被丢弃。已产生的粒子会被追踪到一个很低的追踪下限（11.4 中 e± 默认 1 keV，由 G4EmParameters 设定），剩余能量在那里沉积。阈值决定的是追踪次级粒子的空间分辨率，而不是径迹截断。它作用于电离（δ 电子）、轫致辐射和带电粒子的 e⁺e⁻ 对产生；光电吸收、康普顿散射和 γ 转换默认不受阈值影响，照常产生次级粒子，除非你显式打开。

One global cut is all this week's labs use. Real applications go further, and you should know the names: a G4Region with its own G4ProductionCuts (or /run/setCutForRegion) gives a thin sensitive layer a fine cut while the bulk keeps a coarse one, and the EM constructors G4EmStandardPhysics_option4, G4EmLivermorePhysics and G4EmPenelopePhysics trade speed for low-energy accuracy. None of them is exercised in the labs.

本周的实验只用一个全局阈值。实际应用会更进一步，你应当认识这些名字：带有自己 G4ProductionCuts 的 G4Region（或 /run/setCutForRegion）可以让很薄的灵敏层用细阈值，而大块材料保持粗阈值；EM 构造器 G4EmStandardPhysics_option4、G4EmLivermorePhysics 和 G4EmPenelopePhysics 以速度换取低能精度。这些在实验中都没有练习。

What is real and what is a toy here哪些是真实的，哪些是玩具

Real: the range-to-threshold table (Geant4 11.4 /run/dumpCouples at ten cuts, interpolated log-log, 990 eV floor) and the lead measurements. Toy: the split of the mean loss uses PDG restricted and full Bethe formulas (density effect on, radiative losses off), and the δ-ray rate uses the PDG 1/T² spectrum. That rate reproduces Geant4's muIoni counts in lead to within 7% at all four cuts.

int main(int argc, char** argv)
{
  if (argc < 3) {
    G4cout << "usage: week06 FTFP_BERT|EM macro.mac" << G4endl;
    return 1;
  }
  const std::string list = argv[1];
  if (list != "EM" && list != "FTFP_BERT") {
    // never fall back silently to a physics list the user did not ask for
    G4cerr << "week06: unknown physics list '" << list << "'; use FTFP_BERT or EM" << G4endl;
    return 1;
  }
  auto* runManager = G4RunManagerFactory::CreateRunManager(G4RunManagerType::Serial);
  runManager->SetUserInitialization(new DetectorConstruction());

  if (list == "EM")
    runManager->SetUserInitialization(new EMPhysicsList());   // run B
  else
    runManager->SetUserInitialization(new FTFP_BERT());       // run A

  runManager->SetUserInitialization(new ActionInitialization());
  runManager->Initialize();
  G4UImanager::GetUIpointer()->ApplyCommand("/control/execute " + G4String(argv[2]));
  delete runManager;
  return 0;
}

  G4VSolid* solidWorld =
    new G4Box("World", 0.5 * worldSize, 0.5 * worldSize, 0.5 * worldSize);
  auto* logicWorld = new G4LogicalVolume(solidWorld, worldMat, "World");

  G4double blockSide = 10.0 * cm;

  auto* logicBlock = new G4LogicalVolume(solidBlock, blockMat, "Block");
  new G4PVPlacement(
    nullptr, G4ThreeVector(), logicBlock, "Block",
    logicWorld, false, 0, true);  // last argument: check overlaps at placement

  return physWorld;

void RunAction::EndOfRunAction(const G4Run* run)
{
  fTimer.Stop();
  const G4int n = run->GetNumberOfEvent();
  if (n == 0) return;
  const G4double mean = fSumE / n;
  const G4double rms = std::sqrt(std::max(0., fSumE2 / n - mean * mean));

  auto sorted = [](const std::map<std::string, G4int>& m) {
    std::vector<std::pair<std::string, G4int>> v(m.begin(), m.end());
    std::sort(v.begin(), v.end(), [](auto& a, auto& b) { return a.second > b.second; });
